# Security Policy

## Supported Versions

Security fixes are provided for the latest published Spectral Dot Reservations release. Upgrade to the newest available version before reporting or reproducing an issue.

## Reporting a Vulnerability

Do not disclose suspected vulnerabilities in a public issue. Submit a private report through the repository's Security tab with:

- The affected plugin and WordPress/WooCommerce/PHP versions.
- Reproduction steps and required user role.
- The observed impact.
- A minimal proof of concept when safe to provide.

The maintainers will acknowledge the report, assess severity and supported versions, prepare a tested fix, and coordinate disclosure. Please allow reasonable time for remediation before publishing details.
